# AI Sentiment Analyzer

An AI-powered sentiment analysis web application built using Python, Streamlit, and Hugging Face Transformers.

The application analyzes the sentiment of user-provided text and classifies it as either Positive or Negative.

## Features

- Simple and user-friendly web interface
- Text input for sentiment analysis
- Positive and Negative sentiment classification
- Uses a pre-trained Hugging Face Transformer model
- Real-time sentiment prediction
- Built with Streamlit
- Runs locally in a web browser

## Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- DistilBERT
- PyTorch
